## 🧩 Sobre o Projeto

Este projeto utiliza a biblioteca **OpenCV** para identificar rostos em uma imagem estática. Após a detecção, o programa desenha retângulos ao redor das faces encontradas e exibe o resultado na tela.

## 🧰 Tecnologias Utilizadas

- **Python**
- **OpenCV (cv2)**
- **Haar Cascade** — classificador para detecção de faces.

## ⚙️ Funcionalidades

- 🖼️ Leitura de uma imagem;
- ⚫ Conversão para escala de cinza;
- 🔍 Detecção de rostos;
- 🟦 Desenho de retângulos ao redor das faces;
- 🔢 Exibição das coordenadas das faces detectadas no terminal.

## 📚 Aprendizados

- Leitura e processamento de imagens;
- Conversão de imagens para escala de cinza;
- Utilização do classificador Haar Cascade;
- Detecção de objetos com `detectMultiScale()`;
- Desenho de retângulos com `cv2.rectangle()`.

## 🕹️ Como Executar

1. Instale o OpenCV:

```bash
pip install opencv-python
```

2. Coloque os arquivos `boy.jpg` e `haarcascade_frontalface_default.xml` na mesma pasta do programa.

3. Execute o arquivo Python:

```bash
python main.py
```

4. Pressione qualquer tecla com a janela da imagem selecionada para encerrá-la.
